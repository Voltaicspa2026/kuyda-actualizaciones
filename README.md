# Kuyda — Actualizaciones del Hub TV

Acá se publican las versiones del Hub de televisor de Kuyda.

**Este repositorio NO tiene código fuente**: solo los archivos de instalación,
para que los televisores ya instalados puedan actualizarse sin que alguien
tenga que ir hasta la casa.

El código vive en un repositorio privado aparte.

## Para qué sirve

Cada televisor con Kuyda revisa una vez al día si hay una versión nueva. Si la
hay, avisa en pantalla y la persona confirma con el control. No hace falta
visita técnica.
